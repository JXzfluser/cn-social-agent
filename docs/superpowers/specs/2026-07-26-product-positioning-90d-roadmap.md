## 1. 定位一页纸

### 1.1 一句话

**给程序员 / 独立开发者的 AI 口播制片助手：从想法或链接，稳定产出「能发」的竖屏短视频。**

### 1.2 不是什么

| 我们不是 | 理由 |
|----------|------|
| 通用 Agent 工作台 | 太宽，难形成口碑与留存 |
| CapCut / 剪映替代 | 不做时间轴剪辑深度 |
| 多平台 SCRM / 运营中台 | Phase 2+，成片未被爱之前不做 |

### 1.3 谁付钱、为什么现在

| 项 | 内容 |
|----|------|
| 主用户 | 独立开发者、小团队技术负责人、技术内容创作者 |
| 核心痛 | 有料不会拍；口播脚本散；成片假/平；从想法到可发成本高 |
| 替代方案 | ChatGPT 写稿 + 自己配音录屏 / 剪映模板 / 外包 |
| 我们赢在 | 对话里打磨选题 → 传播结构分镜 → 一键成片 → 单镜可改；技术题材模板更懂 |

### 1.4 价值主张（对外三句）

1. **聊清楚就能开拍**——不必先学剪辑。  
2. **默认交付真画面**——草稿预览和成片分开说。  
3. **改一镜，不重来整片**——迭代成本可控。

### 1.5 产品形态（对内）

```
Chat（导演室）          Video（剪辑台）
想法 / 链接 / 提议  →   同一项目分镜 / 渲染 / 预览 / 下载
     └──────── InsForge Auth · DB · Storage · LLM ────────┘
```

- **InsForge Agent** = 底座能力（身份、会话、技能、工具）  
- **口播成片** = 当前唯一对外主叙事  
- 本地卡片渲染 = **结构草稿**，不得默认冒充成片

### 1.6 质量契约（必须写进产品与 UI）

| 交付档 | 用户可见名称 | 引擎 | 承诺 |
|--------|--------------|------|------|
| L0 结构预览 | 「分镜草稿」 | 本地 TTS + 卡片 + 运镜 | 秒级～分钟级；看结构/旁白/节奏，**不保证画面真实感** |
| L1 可发成片 | 「成片」 | Agnes Video（或等价 T2V）+ TTS | 竖屏真画面；可发平台；失败可解释、可单镜重试 |
| L2 精修（后置） | 「精修」 | 单镜换画 / 换旁白 / 模板 | 不重渲整片 |

**默认路径：Chat 一键制作 → 先出 L0 让用户确认结构 → 一键升级 L1。**  
禁止：按钮写「生成视频」却默认只出 L0。

### 1.7 非目标（本 90 天）

- 多平台一键发布、账号矩阵、SCRM  
- Marketplace / 多 Agent 协作  
- 真人出镜、复杂时间轴、BGM 曲库运营  
- 把产品重新讲成「通用 InsForge Demo」

## 2. 成功怎么算（North Star + 护栏）

### 2.1 North Star

**可发成片率（Ship Rate）**  
定义：近 7 日，完成至少 1 次 L1 成片且用户完成预览或下载的项目数 ÷ 创建了视频项目的用户数。

目标（方向性，锁定前可微调）：

| 阶段 | Ship Rate | 备注 |
|------|-----------|------|
| D30 | ≥ 25% | 证明路径通、预期对齐 |
| D60 | ≥ 40% | 单镜重渲与质检生效 |
| D90 | ≥ 55% | 黄金路径模板化 |

### 2.2 输入 / 过程 / 质量指标

| 类型 | 指标 | D30 | D60 | D90 | 定义 |
|------|------|-----|-----|-----|------|
| 速度 | 想法→首个 L0 预览 | ≤ 90s P50 | ≤ 60s | ≤ 45s | 从「开始制作」到可播草稿 |
| 速度 | L0 确认→首个 L1 成片 | ≤ 8min P50 | ≤ 6min | ≤ 5min | 含排队；超时有状态 |
| 质量 | 成片质检通过率 | ≥ 70% | ≥ 85% | ≥ 90% | 见 §2.3；不通过不得标「成片」 |
| 迭代 | 单镜重渲使用率 | ≥ 15% | ≥ 30% | ≥ 35% | 有 L1 项目中至少重渲 1 镜的占比 |
| 路径 | 链接→成片完成率 | ≥ 10% | ≥ 20% | ≥ 30% | 会话含 URL 且最终 L1 成功 |
| 预期 | L0/L1 误标投诉 | → 0 | 0 | 0 | UI 文案抽检 + 用户反馈 |
| 护栏 | L1 失败可解释率 | ≥ 90% | ≥ 95% | ≥ 98% | 失败屏有原因 + 下一步 |
| 护栏 | 周活创作者 | 建基线 | +50% | +100% | 至少完成 1 次 L0 的用户 |

### 2.3 成片质检门禁（自动化，可演进）

L1 输出前（或输出后标记前）检查；**任一 P0 失败 → 不展示为「成片」**：

| 级别 | 检查项 | 初版规则（可调） |
|------|--------|------------------|
| P0 | 黑场 / 近黑占比 | 抽样帧平均亮度过低的镜 > 40% → 失败 |
| P0 | 运动可读 | 镜内帧差均值过低（近似静帧）→ 失败或降级为草稿 |
| P0 | 音画时长 | \|视频−旁白\| > 0.4s → 失败 |
| P1 | 字幕可读 | 有口播则需可见字幕层或烧录字幕 |
| P1 | 钩子时长 | 第 1 镜 ≥ 2s 且 ≤ 5s（可配置） |
| P2 | 分辨率 | 1080×1920（或约定竖屏） |

> 本地 L0 **不走**「成片」门禁；只打「分镜草稿」标签。

## 3. 90 天 Roadmap

原则：**先对齐承诺，再加深能力，最后放大分发。**  
每阶段一个主题，出口可演示、可量化。

### Phase A · D0–D30「信任」（Stop the bleeding）

**主题：** 用户不再被「假成片」伤害。

| # | 交付 | 验收 |
|---|------|------|
| A1 | UI/文案：L0「分镜草稿」vs L1「成片」；按钮与状态机分离 | 误标抽检 = 0；新用户 1 次走通能说清差别 |
| A2 | 默认制作流：先 L0 → 确认结构 → 升级 L1（Agnes Video） | 默认路径不再直出本地冒充成片 |
| A3 | L1 失败态：原因、重试、回退草稿 | 失败可解释率 ≥ 90% |
| A4 | 成片质检 v0（P0 三项） | 门禁上线；坏片不打成片标 |
| A5 | Chat↔Video 同一项目状态一致 | 两边看到同一 L0/L1 状态 |

**Phase A 出口 Demo：**  
「对话里做程序员选题 → 90 秒内看草稿 → 升级成片 → 预览下载；全程无预期欺诈。」

### Phase B · D31–D60「可控」（Iterate without restart）

**主题：** 改得动，才愿意再做第二条。

| # | 交付 | 验收 |
|---|------|------|
| B1 | 单镜：换引擎 / 重渲 / 重配音 | 单镜重渲使用率 ≥ 30% |
| B2 | 单镜：改旁白 / on_screen 后局部更新 | 改 1 镜无需整片排队 |
| B3 | Agent 导演化：建议「哪几镜该上 L1」与成本提示 | 提议含引擎建议，不只写脚本 |
| B4 | 链接→选题→分镜黄金路径打磨（fetch_url + propose） | 链接→成片完成率 ≥ 20% |
| B5 | 质检 v1 + 运动/黑场自动建议重渲 | 质检通过率 ≥ 85% |

**Phase B 出口 Demo：**  
「成片第 1 镜不行 → 只重渲 hook → 30 秒内替换 → 整片仍可发。」

### Phase C · D61–D90「可复制」（Templates & wedge）

**主题：** 开箱即能发，形成品类心智。

| # | 交付 | 验收 |
|---|------|------|
| C1 | 三套垂直模板：产品更新 / 技术吐槽 / 教程口播 | 模板项目 Ship Rate > 非模板 |
| C2 | 15s「停滑条」优先模式（后再扩 30/60） | 15s 模式占用率可观测；完播代理指标上升 |
| C3 | 用量与配额：L0 宽松 / L1 计量（为商业化铺路） | 有清晰配额 UI；无静默失败 |
| C4 | 基础分析：项目漏斗（创建→L0→L1→下载） | 周会看得到 North Star 与漏斗 |
| C5 | 定位对外一页（官网/README 叙事收敛） | 对外只讲口播制片，不讲大而全工作台 |

**Phase C 出口 Demo：**  
「选『产品更新』模板 → 贴 Changelog 链接 → 15s 成片 → 下载；像固定生产线。」

### 明确 Backlog（90 天外）

- 平台发布、账号绑定、定时  
- 团队空间 / 素材库 / Marketplace  
- 多 Agent、调度、邮件深度  
- 真人数字人出镜

## 4. 关键决策（请确认后锁定）

| ID | 决策 | 推荐 | 备选 |
|----|------|------|------|
| D1 | 对外主叙事 | 口播制片助手 | 通用 Agent 工作台 |
| D2 | 默认「成片」引擎 | Agnes Video L1 | 继续默认本地（**不推荐**） |
| D3 | L0 是否保留 | 保留为草稿预览 | 取消本地（成本高、反馈慢） |
| D4 | 首发垂直 | 程序员 / 独立开发者 | 泛知识付费 |
| D5 | 90 天是否含发布 | **不含** | 含视频号草稿导出（可单列） |

## 5. 度量落地（工程最小集）

每个视频项目持久化（或事件日志）：

```
project_id, user_id, created_at
t_l0_ready, t_l1_requested, t_l1_ready, t_preview, t_download
render_mode_per_scene[], quality_gate_pass, fail_reason
source: chat|workshop, has_url, template_id
```

周报只看 5 个数：Ship Rate、L0 P50、L1 P50、质检通过率、单镜重渲率。

## 6. 风险与对策

| 风险 | 对策 |
|------|------|
| Agnes 贵 / 慢 / 不稳 | L0 保底体验；L1 排队与单镜；配额透明 |
| 垂直过窄 | 模板与提示词可扩；叙事先窄后宽 |
| 工作台历史包袱 | UI 模式保留 Agent，对外与 README 收敛 |
| 质检误杀 | P0 少而狠；先打标降级，不直接删文件 |
