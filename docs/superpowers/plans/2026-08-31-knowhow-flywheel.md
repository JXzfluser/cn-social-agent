# Know-How 知识飞轮重构规划（修订版）

> 核心命题：Agent 是统一入口，Know-How 是知识仓库，所有功能围绕「Agent 处理 → 沉淀 → 应用」形成闭环。

---

## 一、架构修正：Agent 为中心的闭环

### 错误设计（已废弃）
```
用户 → Know-How URL 输入 → 解析入库
```

### 正确设计
```
用户 → Agent 对话 → 内容处理 → Know-How 沉淀 → 项目应用
                ↑                                      │
                └──────────── 知识引用 ────────────────┘
```

**核心原则**：
- Agent 是唯一的内容处理入口
- Know-How 是 Agent 的「长期记忆」和「知识仓库」
- 用户不需要知道 Know-How 的存在，只需要跟 Agent 对话

---

## 二、用户高频场景与闭环设计

### 场景 1：内容采集与整理

**用户动作**：
```
我：帮我整理这个链接的内容，我想深入研究 Agent 原理
   [粘贴] https://xiaolinnote.com/ai/agents
```

**Agent 行为**：
1. 抓取并解析页面内容
2. 识别文章结构（教程/面试题/概念解释）
3. 提取知识片段（概念、代码、案例）
4. 创建/匹配话题「Agent 原理」
5. 写入 Know-How
6. 回复用户：

```
已整理完成，收入 Know-How「Agent 原理」话题：

📚 提取了 12 个知识片段：
   • 概念：ReAct 模式、CoT 推理、工具调用 (5 条)
   • 代码：Function Calling 示例、MCP 协议 (4 条)
   • 案例：大厂面试题解析 (3 条)

🔗 关联知识：检测到与已有话题「RAG」有 3 处交叉引用

接下来你可以：
1. 继续深入研究这个话题
2. 基于这些知识生成视频脚本
3. 出几道面试题测试自己
4. 查看知识图谱
```

**闭环点**：
- 采集 → 沉淀 → 立即可用
- 自动关联已有知识
- 提供下一步行动选项

### 场景 2：项目深度探索

**用户动作**：
```
我：基于「Agent 原理」这个话题，帮我做一个深度研究
```

**Agent 行为**：
1. 从 Know-How 加载该话题所有知识
2. 分析知识覆盖度（哪些概念有了，哪些缺失）
3. 提出研究问题：

```
「Agent 原理」话题已有 42 条知识，覆盖度 68%。

📊 知识分布：
   ✅ 概念：ReAct、CoT、工具调用、MCP
   ✅ 实践：Function Calling、错误处理
   ⚠️ 缺失：多 Agent 协作、记忆机制、安全边界

建议深入方向：
1. 补充「多 Agent 协作」知识（当前为 0）
2. 研究「记忆机制」的最佳实践
3. 对比不同框架的实现差异

你想从哪个方向继续？
```

**闭环点**：
- 知识驱动研究，不是凭空探索
- 自动识别知识缺口
- 引导用户补充知识

### 场景 3：内容创作加速

**用户动作**：
```
我：我想做一个「Agent 入门」的视频，用我沉淀的知识
```

**Agent 行为**：
1. 从 Know-How 检索「Agent」相关知识
2. 按学习路径排序（概念 → 实践 → 案例）
3. 生成脚本大纲：

```
基于你的知识库，生成视频大纲：

🎬 「Agent 入门：从概念到实践」

1. 开场：什么是 Agent？(引用 kh_001)
2. 核心概念：ReAct 模式 (引用 kh_005, kh_012)
3. 实践：Function Calling 示例 (引用 kh_023)
4. 案例：实际应用场景 (引用 kh_031)
5. 总结：Agent vs 传统工作流

📚 共引用 8 条知识，来自 3 个话题
   • Agent 原理 (5 条)
   • RAG (2 条)
   • Prompt 工程 (1 条)

[生成完整脚本] [调整大纲] [添加更多素材]
```

**闭环点**：
- 知识直接变成创作素材
- 引用可溯源
- 创作过程反哺知识库

## 三、Agent 工具集增强

### 3.1 新增工具：`ingest_url`

**功能**：抓取并解析 URL，提取知识片段

**输入**：
```json
{
  "url": "https://xiaolinnote.com/ai/agents",
  "topic_hint": "Agent 原理",  // 可选
  "tags": ["面试", "原理"]      // 可选
}
```

**输出**：
```json
{
  "ok": true,
  "topic_key": "agent-principles",
  "topic_name": "Agent 原理",
  "fragments": [
    {
      "type": "concept",
      "title": "ReAct 模式",
      "content": "...",
      "source_url": "..."
    }
  ],
  "related_topics": ["rag", "prompt-engineering"],
  "summary": "提取了 12 个知识片段，已收入 Know-How"
}
```

**实现要点**：
- 支持 HTML、PDF、Markdown
- 自动识别内容结构（标题、段落、代码块）
- 按语义切片，不是按段落硬切
- 话题匹配：先匹配已有，无匹配则创建

### 3.2 增强工具：`query_knowledge_base`

**当前**：返回纯文本搜索结果

**增强**：
```json
{
  "ok": true,
  "query": "ReAct 模式",
  "results": [
    {
      "id": "kh_005",
      "topic_key": "agent-principles",
      "type": "concept",
      "title": "ReAct 模式的核心思想",
      "content": "...",
      "source": {"url": "...", "title": "..."},
      "usage_count": 8,
      "confidence": 0.92
    }
  ],
  "knowledge_gaps": ["多 Agent 协作", "记忆机制"],
  "related_questions": ["ReAct 和 CoT 有什么区别？"]
}
```

**增强点**：
- 结构化返回，不是纯文本
- 显示使用频率和置信度
- 识别知识缺口
- 推荐相关问题

### 3.3 新增工具：`analyze_topic`

**功能**：分析话题知识覆盖度，识别缺口

**输入**：
```json

}
```

**输出**：
```json
{
  "ok": true,
  "topic_key": "agent-principles",
  "stats": {
    "total_fragments": 42,
    "by_type": {"concept": 18, "practice": 15, "pitfall": 9},

  "coverage": {
    "covered": ["ReAct", "CoT", "工具调用", "MCP"],

    "补充「多 Agent 协作」知识（当前为 0）",
    "研究「记忆机制」的最佳实践"

```

### 3.4 新增工具：`generate_learning_path`

## 五、闭环设计：每个功能的输入输出

### 5.1 内容采集闭环

```
用户粘贴 URL 到 Agent
    ↓
Agent 调用 ingest_url 工具
    ↓
解析内容 → 提取知识片段 → 匹配话题
    ↓
写入 Know-How
    ↓
Agent 回复：已整理完成 + 下一步建议
    ↓
用户选择下一步（深入研究/生成视频/出面试题）
    ↓
调用相应工具，引用刚沉淀的知识
    ↓
使用反馈（usage_count++）
    ↓
驱动更多采集
```

### 5.2 项目探索闭环

```
用户：深入研究「Agent 原理」
    ↓
Agent 调用 analyze_topic 工具
    ↓
分析覆盖度 → 识别知识缺口
    ↓
Agent 回复：当前状态 + 建议补充方向
    ↓
用户选择补充方向
    ↓
Agent 搜索/抓取补充内容
    ↓
写入 Know-How
    ↓
覆盖度提升 → 可以进入下一阶段
```

### 5.3 内容创作闭环

```
用户：基于知识库做视频
    ↓
Agent 调用 generate_learning_path (goal=video)
    ↓
生成脚本大纲（引用知识条目）
    ↓
用户确认/调整
    ↓
生成完整脚本
    ↓
进入视频编辑页
    ↓
完成视频 → 回写 Know-How（工作流记录）
    ↓
下次创作复用这个工作流
```

### 5.4 技能成长闭环

```
用户：这个月学到了什么？
    ↓
Agent 统计知识增长、使用频率
    ↓
生成成长报告
    ↓
识别薄弱环节
    ↓
建议下一步学习方向
    ↓
用户开始新一轮采集
```

## 八、设计原则

### 8.1 Agent 是唯一入口

- 用户不需要知道 Know-How 的存在
- 所有录入、查询、应用都通过 Agent 对话
- Know-How 是 Agent 的「长期记忆」

### 8.2 渐进式复杂度

- 新用户：粘贴链接 → Agent 整理 → 完成
- 中级用户：查看仪表盘 → 选择话题 → 深入探索
- 高级用户：技能图谱 → 学习路径 → 知识网络

### 8.3 知识驱动

- 每个功能都有知识库支撑
- 每次使用都产生知识
- 知识越用越有价值

### 8.4 可度量

- 知识条目有使用次数
- 话题有覆盖度
- 用户有技能成长曲线
