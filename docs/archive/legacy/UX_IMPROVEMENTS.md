#### [P1-04] 舆情危机 → 内容生成快捷路径 ✅

- 过长时 Toast 警告，不发送
- 增加敏感词过滤（复用已有的 /api/sensitive-words/check 端点）

#### [P1-07] 全局搜索支持草稿内容搜索 ✅
- 扩展 _doSearch() 支持搜索草稿
- 草稿搜索调用 /api/drafts?q=（需新增后端支持）

#### [P1-08] 草稿拒绝历史展示 ✅
