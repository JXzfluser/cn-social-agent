## 二、UI 布局全景（workbench/index.html 单页应用）

### 2.1 顶层导航（header）

```
[内容工作台 | Agent]  Agent · 项目 · 画布 · 知识卡片 · 短视频 · 主题资产   [当前内容项目chip]  ...  [LLM chip] [平台] [账号▾]
```

- **6 大工作区（mode）**：Agent（chat 主界面）、项目（project board）、画布（canvas）、知识卡片（cards）、短视频（video）、主题资产（assets）
- **账号菜单**：「人口图鉴（高级）」→ 独立暗色 iframe（`population-atlas.html`）
- **顶栏芯片**：LLM 模型/路由切换（偏好同步账号）、平台凭证（微信/头条）、当前内容项目上下文 chip
- 强制口播模式：`?mode=video`

### 2.2 主交互区（Agent composer 四种意图）

```
[对话] [口播] [讲解] [知识卡片]  ← composerIntent 单选
```

一个输入框 + 意图选择驱动四条流水线，Agent 消息内嵌视频卡/期刊卡/建议卡。这是**当前产品的一等入口**——所有工坊都从"聊"进入。

### 2.3 短视频工坊（video）：4 步流水线

```
1 内容 → 2 构建 → 3 预览 → 4 成片
（选题/模板 15s·60s·90s·120s·180s | 9:16 竖屏（抖音）/ 16:9 横屏）
```

- L0 分镜草稿 → 确认 → 升级 L1 成片 → 下载（本地优先，Storage 回源）
- 讲解演示为次要轨道（网页舞台 + 录屏），UI 明确标注"默认请走口播"

### 2.4 专业化视图

- **项目看板**（board）：候选 · 进行中 · 可导出 三泳道，卡片拖拽，详情抽屉（08-16 canvas/project 增强已落地）
- **知识画布**（canvas）：节点/有向边、连边标签、minimap、AI organize（守卫式）、模板（漏斗/脚本结构/SWOT）
- **知识卡片**（cards）：扫描 · 编辑 · 导出，平台发布（微信/头条）
- **主题资产**（assets）：按主题聚合期刊·短视频·证据（`topic_key` 记忆）
- **人口图鉴**（atlas）：暗色数据可视化（高级/实验）

### 2.5 已实施的 UX 基础（06-13~14 已验证 ✅）

深色模式、响应式断点、骨架屏、快捷键（G+1~9、?、/）、i18n（i18next + LOCALES）、健康检查 dot、SSE 通知、限流/CSRF。这批"工程性 UX"已就位，**不是当前迭代重点**。

## 四、产值率分析（value-per-cost 矩阵）

> 产值率 = 用户价值 × 使用频率 /（开发成本 + 运行成本）。运行成本大头 = LLM token + 视频渲染时间。

| 功能 | 用户价值(1-5) | 频率(1-5) | LLM/渲染成本 | 开发成本 | 产值率 | 结论 |
|------|:---:|:---:|:---:|:---:|:---:|------|
| 口播 L0 分镜 → L1 成片 | 5 | 5 | 中（一次成片） | 已投 | **S** | 绝对核心，继续压榨质量/速度 |
| 期刊质检（成刊未达标护栏） | 4 | 4 | 低 | 已投 | **S** | 信任关键，保住 |
| Chat 一键制作（Lead Agent） | 5 | 4 | 低 | 已投 | **A+** | 默认入口，补 clarify 体验 |
| 内容项目 Content Project | 4 | 4 | 低 | 已投 | **A** | 上下文聚合，继续深化 |
| 热点选题引擎（已落地） | 4 | 4 | 低（规则打分） | 已投 | **A** | 已闭环，聚焦中文源 + 交接质量 |
| 多平台发布（微信/头条/抖音/小红书） | 4 | 3 | 低 | 已投 | **A-** | 已有真实实现，跟踪发布回执 |
| 知识卡片/期刊生成 | 4 | 3 | 中 | 已投 | **A-** | 低成本多产出，值得加 |
| 画布（编辑/组织） | 3 | 3 | 低 | 已投 | **B+** | 保留，别过度投资 |
| 自动连接器/流水线（S2/S3 recipe 引擎） | 3 | 3 | 低 | 已投 | **B+** | 引擎已落地，扩展等真实使用数据 |
| 人口图鉴 / 讲解演示 | 2 | 2 | 低 | 已投 | **B-** | 高级/实验定位 OK |
| 成本计量后端（usage/meter） | 3 | 3 | 低 | 已投 | **A−*** | *后端已就位，**UI 未接入**，接入即收益 |
| 舆情/变现/团队/通用工作流（遗产） | - | - | - | - | **E** | 已物理删除 ✅ 无需再处理 |

**核心洞察：产值率最高的不是"新功能"，而是 ① 黄金路径的端到端稳定（想法→能发），② 质检护栏，③ 选题入口，④ 已在手的多平台发布出口。这四者都是"让已有 pipeline 多产出"的杠杆，而不是加新维度。**

## 五、产品迭代建议（按优先级）

### P0 —— 黄金路径打磨（当前最高产值杠杆）

1. **口播 L0→L1 端到端成功率**：把"从想法到能发"的失败率压到最低。重点：topic 提炼失败（422）、单镜重试体验、渲染进度恢复（wbmeta 持久化已实现，验证刷新后恢复路径）。
2. **质检护栏强化**：`flow_not_truncated` 类硬指标继续收口；把质检从"事后拦截"提升到"构建中实时提示"（build 时高亮，而非发布时驳回）。
3. **成本可见性接入 UI**：`usage/meter.py`（单位成本估算 + 周报 API `/api/usage/summary`）后端已就绪，但**前端未接入**（index.html 无成本展示）。把"每部成片 token 估算 + 渲染耗时"接到成片卡片——对面独立开发者，"这条片子花了多少钱/多久"是硬需求，也是收费切入点。**这是现成后端换 UI 接入，投入最低的 P0。**

### P1 —— 选题 & 聚合（让 pipeline 填满）

4. **热点引擎已落地，聚焦收尾**：`tools/hotspot_engine.py`（score/why/去重/资产碰撞）+ `hotspot_handoff.py`（research_notes + propose_* 交接）+ `/api/hotspots/handoff` 已在。剩余高产值项：**稳定中文源覆盖（现仅 V2EX）+ 交接体验打磨**。这是"给用户每天一个值得做的主题"的高频入口。
5. **内容项目深化**：项目作为唯一真相（todos / production_plan / evidence 写回），让用户"换一天回来还能接着做"。S2 连接器（web_fetch/github ingest）可先做 ingest 侧——成本低、喂饱 pipeline。

### P2 —— 低成本多产出（横向扩展）

6. **知识卡片/期刊**：同一 Content Project 一键出 卡片 + 期刊 + 口播 三件套。边际 LLM 成本低（一次研究多次成刊），是产值率的乘法器。**建议做成"一链三出"按钮**。
7. **画布维持现状**，只在用户实际使用后按数据迭代（不要提前堆 AI 能力）。

### P3 —— 明确不做 / 收敛

8. **遗产模块已物理删除**——无需动作。⚠️ 提醒：确保 UI 无死链接/残留入口引用已删端点（06 遗产 API 曾挂载多组路由，现 `app.py` 仅挂 20 组，核对前端是否有引用已删 `/api/radar`、`/api/review` 等路径的代码）。
9. **90 天内不做**：Marketplace、真人出镜、专做 InsForge Demo（多平台发布已是真实实现，不在"不做"列）。

### 工程建议（支撑以上）

10. **统一"一次研究多成刊"数据流**：`research_notes + evidence_pack` 是黄金资产的中间态，确保三产线（卡片/期刊/口播）都从同一中间态产出，避免每线各做一次研究。
11. **质检规则单一事实源**（已做过 flow 修复）：继续保持 `DANGLING_TAIL_RE` 这类"构建期与质检期共享常量"的模式，防止阈值漂移。
12. **自动化已不是"未做"**：recipe 引擎（3 个 recipe，2 个默认启用）已落地。扩展方向是**观察真实使用数据后加 recipe**，而不是现在堆更多自动化种类。

## 七、一句话结论

**产品方向已正确（口播制片 + Content OS），产值率最高的动作是"把想法→能发"的黄金路径做到闭眼可用，再把现成的热点引擎（已落地）与成本计量（后端就绪、UI 未接）接入体验闭环，用一链三出让 pipeline 被填满、被复用；遗产模拟模块已物理删除，只需核对前端无死链。**
