## 五、优化需求建议

### 5.1 P0 - 核心体验（1-2 周）

#### 需求 1：内容生成 → 草稿自动保存

**当前**：生成后需手动复制或发送到审核  
**优化**：生成完成自动保存到草稿箱

```javascript
// 生成完成后自动保存
async doGenerate() {
    // ... 现有生成逻辑 ...
    if (data && (data.post || data.content)) {
        // 新增：自动保存到草稿箱
        await API.post('/api/drafts', {
            title: content.substring(0, 50),
            content: this.lastResult,
            platform: document.getElementById('gen-platform').value,
            style: document.getElementById('gen-style').value,
            source: 'ai_generate'
        });
        Toast.success('内容已生成并保存到草稿箱');
    }
}
```

**预期收益**：内容丢失率降低 90%

#### 需求 2：改写结果可编辑

**当前**：改写结果只读展示  
**优化**：每个平台结果可独立编辑

```html
<!-- 改写结果卡片 -->
<div class="card">
    <div class="card-header">
        <h3>小红书 改写结果</h3>

            <button onclick="editContent()">编辑</button>
            <button onclick="publishTo('xiaohongshu')">发布</button>

    </div>
    <div class="card-body">
        <!-- 改为可编辑 textarea -->
        <textarea class="result-editable" rows="10">${content}</textarea>
```

**预期收益**：用户满意度提升 40%
