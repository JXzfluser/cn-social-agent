# 30 天技术内容操作系统 · FDE 试点

> 对外卖的是**结果**：稳定产出「能发」的技术口播 / 知识卡，并跑通发布 SOP。  
> 工作台是交付武器，不是货架订阅。

---

## 一句话

**30 天内，帮技术型团队把「选题 → 成片/卡片 → 发布」流水线装上并跑稳。**

---

## 谁适合

- 技术 SaaS / 开发者工具 / 独立产品团队
- 内容或品牌由创始人、技术负责人或市场同学兼着做
- 已有「料」（产品更新、开源、招聘、行业观点），但产能不稳、成片假/平、发不出去

**暂不主攻：** 纯 MCN 矩阵号、纯个人订阅自助用户。

---

## 问题（客户侧）

| 痛点 | 今天常见做法 | 试点后 |
|------|--------------|--------|
| 有料不会拍 | ChatGPT 写稿 + 自己配音 / 外包 | 对话定选题 → L0 草稿 → L1 成片 |
| 选题靠感觉 | 刷榜、临时找灵感 | 热点引擎 + 主题资产可复用 |
| 发不出去 | 剪辑完还要另开平台 | 抖音 / 公众号半自动或 API SOP |
| 成本不可见 | 成片费用心里没数 | 周报：L0/L1 次数与估算成本 |

---

## 交付物（30 天）

1. **客户实例部署** — 独立 env / InsForge / 工作台；密钥与平台账号隔离  
2. **垂直技能包配置** — 默认 `tech-saas-content`；可选 `hiring-insight-cards`  
3. **选题库 v0** — ≥12 条可拍选题（含来源与角度）  
4. **周产能流水线** — 热点扫描 → 选题确认 → L0 → L1/卡片 → 发布复盘  
5. **发布 SOP** — 抖音、微信公众号优先；小红书半自动说明  
6. **培训** — 1 次上手 + 1 次复盘；书面操作备忘  
7. **用量周报** — L0/L1/卡片/发布次数与估算成本  

### 成功标准（签约时写死数字）

默认建议（可按客单调整）：

| 指标 | 目标 |
|------|------|
| 可发成片 / 知识卡 | 4 周合计 ≥ **8** 条「可发」产出（L1 成片或已导出可发卡片） |
| 真实发布 | ≥ **1** 条在抖音或公众号真实发出 |
| 流水线可复现 | 客户方至少 **1** 人能独立走通「热点 → L0 → 发布」 |
| 案例授权 | 允许匿名案例或素材授权（首单可打折换） |

## 报价锚点

| 档位 | 价格 | 说明 |
|------|------|------|
| 标准试点 | **¥5 万** / 30 天 | 含部署、陪跑、技能配置、周报 |
| 轻量试点 | **¥3 万** / 30 天 | 产出目标下调（如 ≥5 条）；适合早期团队 |
| 加强试点 | **¥8 万** / 30 天 | 含更多 L1 预算、双平台发布陪跑、招聘卡系列 |
| 续约 retainer | **¥1–3 万** / 月 | 周节奏陪跑 + 技能迭代 |
| 平台年费（试点后） | 面议 | 实例托管 + 用量；**不上自助 SaaS 套餐页** |

**不含（写进合同）：** 账号矩阵运营、付费投流、真人出镜拍摄、全自动小红书 API、通用 SCRM、7×24 运维。

L1（Agnes 等）云费用：按实际用量另计或包进加强档；周报可见。

## 我们怎么干活（FDE）

| 周次 | 焦点 |
|------|------|
| W1 | 部署、账号、演示剧本、首批 4 选题、第 1 条 L0→发布演练 |
| W2 | 定周节奏；产出 2–3 条；修卡点；抽回可复用模板 |
| W3 | 产能爬坡；客户方独立操作；用量与成本对齐 |
| W4 | 达成成功标准；复盘；续约（retainer / 年费）或礼貌结束 |

每周五输出 **卡点清单** → 决定下周产品改什么（驻场 → 主仓飞轮）。
